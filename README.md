# Library REST API

A RESTful API built with **Spring Boot** and **MySQL** for managing library books with complete CRUD operations, database persistence with JPA/Hibernate, input validation, and interactive OpenAPI (Swagger) documentation.

> **Course:** IN3101 - Enterprise Application Development  
---

## 🛠 Tech Stack

- **Java:** JDK 21
- **Framework:** Spring Boot 4.1.2
- **Persistence:** Spring Data JPA & Hibernate
- **Database:** MySQL 8.4 (Dockerized)
- **Validation:** Jakarta Bean Validation (`@NotBlank`, `@PositiveOrZero`, `@Valid`)
- **API Documentation:** SpringDoc OpenAPI 3.1 & Swagger UI
- **Build Tool:** Apache Maven (via Maven Wrapper `./mvnw`)
- **Testing:** Spring Boot Test, JUnit 5, MockMvc, and H2 (test scope)

---

## 🏛 Architecture

The application implements a standard four-layer enterprise architecture:

```
Postman / Client
       │ (HTTP JSON Requests)
       ▼
BookController (@RestController)
       │ (Calls business logic)
       ▼
  BookService (@Service)
       │ (Calls data access layer)
       ▼
BookRepository (JpaRepository<Book, Long>)
       │ (Hibernate ORM / SQL)
       ▼
 MySQL Database (library_db)
```

- **Controller (`controller.BookController`):** Exposes HTTP endpoints, maps JSON request/response bodies, handles HTTP status codes, and applies validation.
- **Service (`service.BookService`):** Encapsulates business logic between the controller and data access layer.
- **Repository (`repository.BookRepository`):** Extends `JpaRepository<Book, Long>` to execute automated database operations.
- **Entity (`model.Book`):** JPA Entity mapped to the `book` database table.

## 🚀 Getting Started

### Prerequisites

- **Docker Desktop** (Engine & Docker Compose v2)
- **JDK 21** installed (for local builds and development)

---

### 1. Configure Environment Variables

Create a `.env` file in the project root by copying `.env.example`:

```bash
cp .env.example .env
```

Ensure `.env` contains:
```env
DB_ROOT_PASSWORD=root123
```
*(Note: `.env` is listed in `.gitignore` and is never committed to source control).*

---

### 2. Build the Application JAR

Package the Spring Boot application using the Maven Wrapper:

```bash
# On Linux / macOS:
./mvnw clean package -DskipTests

# On Windows:
.\mvnw.cmd clean package -DskipTests
```

This generates `target/library-api-0.0.1-SNAPSHOT.jar`.

---

### 3. Run with Docker Compose (Recommended)

Start both the API and MySQL database together:

```bash
docker compose up --build -d
```

- **API Container (`api`):** Accessible at `http://localhost:8080`
- **Database Container (`db`):** Accessible at `localhost:3307` (Mapped from internal port `3306`)
- **Data Persistence:** Database files are persisted across container restarts in the Docker named volume `library-data`.

To inspect running services:
```bash
docker compose ps
docker compose logs -f api
```

To stop services (preserving data volume):
```bash
docker compose down
```

---

### 4. Alternative: Running the Standalone Docker Image

You can also build and run the Docker image standalone:

```bash
# Build the Docker image
docker build -t library-api .

# Run the container (requires MySQL database reachable at configured host)
docker run --name api-test -p 8080:8080 library-api
```

---

### 5. Local Development (Without Docker Compose)

To run the application locally on your host machine against a local MySQL instance:

```bash
# On Linux / macOS:
./mvnw spring-boot:run

# On Windows:
.\mvnw.cmd spring-boot:run
```

## 📖 REST API Endpoints

| Method | URL | Description | Success Status | Error Status |
| :--- | :--- | :--- | :--- | :--- |
| **GET** | `/api/books` | Retrieve a list of all books | `200 OK` | — |
| **GET** | `/api/books/{id}` | Retrieve a specific book by ID | `200 OK` | `404 Not Found` |
| **POST** | `/api/books` | Create a new book record | `201 Created` | `400 Bad Request` |
| **PUT** | `/api/books/{id}` | Update an existing book by ID | `200 OK` | `404 Not Found` / `400 Bad Request` |
| **DELETE** | `/api/books/{id}` | Delete a book by ID | `204 No Content` | `404 Not Found` |

### Sample Request Body (JSON)

```json
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "isbn": "9780132350884",
  "price": 4500.00
}
```
