# Library REST API

A RESTful API built with **Spring Boot** and **MySQL** for managing library books with complete CRUD operations, database persistence with JPA/Hibernate, input validation, and interactive OpenAPI (Swagger) documentation.

> **Course:** IN3101 - Enterprise Application Development  
---

## 🛠 Tech Stack

- **Java:** JDK 21
- **Framework:** Spring Boot 4.1.2
- **Persistence:** Spring Data JPA & Hibernate
- **Database:** MySQL 8.4 (Dockerized)
- **Validation:** Jakarta Bean Validation (`@NotBlank`, `@PositiveOrZero`, `@Valid`)
- **API Documentation:** SpringDoc OpenAPI 3.1 & Swagger UI
- **Build Tool:** Apache Maven (via Maven Wrapper `./mvnw`)
- **Testing:** Spring Boot Test, JUnit 5, MockMvc, and H2 (test scope)

---

## 🏛 Architecture

The application implements a standard four-layer enterprise architecture:

```
Postman / Client
       │ (HTTP JSON Requests)
       ▼
BookController (@RestController)
       │ (Calls business logic)
       ▼
  BookService (@Service)
       │ (Calls data access layer)
       ▼
BookRepository (JpaRepository<Book, Long>)
       │ (Hibernate ORM / SQL)
       ▼
 MySQL Database (library_db)
```

- **Controller (`controller.BookController`):** Exposes HTTP endpoints, maps JSON request/response bodies, handles HTTP status codes, and applies validation.
- **Service (`service.BookService`):** Encapsulates business logic between the controller and data access layer.
- **Repository (`repository.BookRepository`):** Extends `JpaRepository<Book, Long>` to execute automated database operations.
- **Entity (`model.Book`):** JPA Entity mapped to the `book` database table.

## 🚀 Getting Started

### Prerequisites

- **JDK 21** installed
- **Docker Desktop** (or local MySQL 8.4 instance)

### 1. Start the MySQL Database

Start the containerized MySQL 8.4 instance using Docker Compose:

```bash
docker compose up -d
```

This starts MySQL with database `library_db` on port `3306`.

### 2. Run the Application

Run the application using the Maven Wrapper:

```bash
# On Linux / macOS:
./mvnw spring-boot:run

# On Windows:
.\mvnw.cmd spring-boot:run
```

Once started, the embedded Tomcat web server will be listening on:
```
http://localhost:8080
```

## 📖 REST API Endpoints

| Method | URL | Description | Success Status | Error Status |
| :--- | :--- | :--- | :--- | :--- |
| **GET** | `/api/books` | Retrieve a list of all books | `200 OK` | — |
| **GET** | `/api/books/{id}` | Retrieve a specific book by ID | `200 OK` | `404 Not Found` |
| **POST** | `/api/books` | Create a new book record | `201 Created` | `400 Bad Request` |
| **PUT** | `/api/books/{id}` | Update an existing book by ID | `200 OK` | `404 Not Found` / `400 Bad Request` |
| **DELETE** | `/api/books/{id}` | Delete a book by ID | `204 No Content` | `404 Not Found` |

### Sample Request Body (JSON)

```json
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "isbn": "9780132350884",
  "price": 4500.00
}
```

## 🧪 Testing

### Running Automated Tests

Run the complete test suite (unit and MockMvc integration tests):


A pre-configured Postman Collection is provided in the repository:
